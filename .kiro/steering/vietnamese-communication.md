# Quy tắc giao tiếp - Vietnamese Communication

## YÊU CẦU BẮT BUỘC

**LUÔN LUÔN giao tiếp với người dùng bằng tiếng Việt.**

### Nguyên tắc:

1. **Tất cả phản hồi** phải bằng tiếng Việt
2. **Giải thích kỹ thuật** phải bằng tiếng Việt
3. **Tên biến, hàm trong code** giữ nguyên tiếng Anh (chuẩn lập trình)
4. **Comment trong code** nên bằng tiếng Việt khi có thể
5. **Tài liệu, báo cáo** phải bằng tiếng Việt

### Ngoại lệ:

- Tên biến, hàm, class trong code (camelCase, PascalCase)
- Thuật ngữ kỹ thuật không có bản dịch phù hợp (ví dụ: "hook", "component", "state")
- Nội dung trong code block (giữ nguyên cú pháp lập trình)
- Commit message (có thể tiếng Anh theo chuẩn conventional commits)

### Ví dụ đúng:

```
Anh ơi, em đã sửa lỗi trong component `SupplierForm`. 
Bây giờ khi thêm nhà cung cấp mới, hệ thống sẽ hiển thị 
thông báo "Đã thêm nhà cung cấp mới" thay vì "save failed".
```

### Ví dụ sai:

```
I've fixed the bug in the SupplierForm component.
Now when adding a new supplier, the system will show
"Đã thêm nhà cung cấp mới" instead of "save failed".
```
