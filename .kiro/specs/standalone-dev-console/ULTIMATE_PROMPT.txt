## 🔑 CORE FEATURE 1: AI PROVIDER ROTATION
=================================================================

File: backend/src/services/AIProvider.ts

REQUIREMENTS:
1. Class AIProviderRotation with:
   - Load providers from config
   - Auto-rotate between available providers
   - Track usage (tokens, requests, cost)
   - Auto-skip rate-limited providers
   - Auto-retry with different provider on error
   - Support 4 strategies: round_robin, priority, cost, smart

2. Provider interface:
interface Provider {
  id: string;
  name: string;
  type: 'anthropic' | 'openai';
  model: string;
  apiKey: string;
  priority: number;
  rateLimit: {
    tokensPerMinute: number;
    requestsPerMinute: number;
  };
  usage: {
    tokensUsed: number;
    requestsUsed: number;
    lastReset: Date;
  };
  status: 'active' | 'rate_limited' | 'error';
  cost: {
    inputTokenCost: number;
    outputTokenCost: number;
    totalSpent: number;
  };
  client: any; // SDK instance
}

3. Main method signature:
async callAI(
  prompt: string,
  options?: {
    systemPrompt?: string;
    maxTokens?: number;
    taskType?: string;
  }
): Promise<{
  content: string;
  usage: { inputTokens, outputTokens, totalTokens };
  provider: string;
  cost: number;
}>

4. Features:
- startResetTimer(): Reset usage counters every 60s
- isProviderAvailable(): Check rate limits (leave 10% buffer)
- selectProvider(): Choose based on strategy
- callClaude(): Use @anthropic-ai/sdk
- callOpenAI(): Use openai SDK
- getProviderStats(): Return stats for dashboard

5. Export singleton:
export const aiProvider = new AIProviderRotation(config);

IMPLEMENTATION DETAILS:
- Use Map<string, Provider> for providers
- currentIndex for round-robin
- Reset counters using setInterval(60000)
- Handle 429 errors with auto-retry
- Calculate cost: (inputTokens * inputCost + outputTokens * outputCost) / 1M

## 🔌 WEBSOCKET SERVER
=================================================================

File: backend/src/websocket/index.ts

import { Server } from 'socket.io';
import { aiProvider } from '../services/AIProvider';

export function setupWebSocket(httpServer) {
  const io = new Server(httpServer, {
    cors: { origin: 'http://localhost:5173' }
  });
  
  io.on('connection', (socket) => {
    console.log('Client connected:', socket.id);
    
    // Chat with AI
    socket.on('agent.chat', async (data) => {
      try {
        const response = await aiProvider.callAI(data.message, {
          systemPrompt: 'You are Kiro, a helpful AI dev assistant.',
          maxTokens: 4096
        });
        
        socket.emit('agent.response', response);
      } catch (error) {
        socket.emit('agent.error', { error: error.message });
      }
    });
    
    socket.on('disconnect', () => {
      console.log('Client disconnected:', socket.id);
    });
  });
  
  return io;
}
