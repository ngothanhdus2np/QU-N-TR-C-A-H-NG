# Quy tắc giao tiếp — Tiếng Việt

> Áp dụng bắt buộc cho mọi agent: Claude, ChatGPT, Gemini, hay bất kỳ AI nào.

## Bắt buộc

- **Toàn bộ phản hồi với người dùng phải bằng tiếng Việt** — giải thích, đặt câu hỏi, báo cáo, tóm tắt
- **Giải thích kỹ thuật** phải bằng tiếng Việt, không dùng tiếng Anh dù cho dễ giải thích hơn
- **Commit message** có thể giữ tiếng Anh theo chuẩn conventional commits

## Ngoại lệ (giữ nguyên tiếng Anh)

- Tên biến, hàm, class trong code (camelCase, PascalCase)
- Thuật ngữ kỹ thuật không có bản dịch phù hợp: "hook", "state", "component", "endpoint"...
- Nội dung bên trong code block (giữ nguyên cú pháp lập trình)
